# GS-MTX-010 — Counterparty Insulation Matrix

| Counterparty Type | Risk Level | Direct Relationship Permitted? | Required Intermediary | Disclosure Requirement | Legal Boundary |
|---|---|---|---|---|---|
| Hostile state | Extreme | No | Consortium or partner org | Counsel-reviewed only | No sanctions evasion |
| Neutral state | Moderate | No | Subsidiary or partner | Standard filings | Full compliance |
| Sovereign wealth fund | High | No | Trust with disclosed ownership | Beneficial ownership on request | No concealed control |
| Large corporation | High | No | Subsidiary or consortium | Standard filings | No anti-competitive collusion |
| Mid-size corporation | Moderate | Case-by-case | Partner org | Standard filings | Full compliance |
| Individual donor | Low–high | Yes, within concentration limits | None if under threshold | Tax filings as required | No wage substitution |
| Partner non-profit | Low | Yes | None | Standard filings | No self-dealing |
| Competitor | Moderate | Yes, with firewalls | None | Conflict-of-interest disclosure | No collusion |
| Sanctioned entity | Prohibited | No | None | None | Absolute prohibition |
